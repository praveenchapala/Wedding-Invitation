# Wedding Invitation Website

A modern, interactive wedding invitation website developed as a **client-style frontend project**.

The project focuses on creating a premium digital invitation experience rather than a traditional static webpage. It combines responsive UI design, cinematic animations, interactive sections, background music, real-image presentation, RSVP functionality, venue information, and performance-conscious frontend development.

---

## Project Overview

This project was developed as a **custom wedding invitation website for a client**.

The goal was to replace a traditional static wedding invitation with an interactive digital experience that users can access directly from a browser.

The website was designed around three main principles:

- Elegant visual design
- Smooth and meaningful animations
- Responsive experience across desktop and mobile devices

Rather than using a pre-built wedding template, the interface and animations were developed specifically for the project requirements.
